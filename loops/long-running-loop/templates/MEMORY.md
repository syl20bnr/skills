# Memory

The few concepts no round may ever forget, whatever it works on. Every round reads this file
first and follows it over anything else it reads; a conflict with PLAN.md or the inbox goes
under "Questions" in PROGRESS.md, and the round keeps to this file meanwhile.

Reserved for fundamentals: a principle that shapes every decision (where code belongs, what
must never happen, how the work is judged). Not for tasks, steps, findings, commands, paths
or anything a single item needs: those go in PLAN.md (rules, decisions) or PROGRESS.md. Keep
it to a handful of entries, each a short paragraph saying the concept and why it holds.

Only the user adds, changes or removes an entry, directly or through an inbox item that says
"remember" or "memory"; rounds never edit this file on their own.
